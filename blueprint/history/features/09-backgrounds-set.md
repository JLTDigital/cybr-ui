# Feature: Backgrounds set

**From build-plan:** feature 9
**Build attempt:** 1
**Branch:** feature/backgrounds-set
**Status:** verified

## Goal

Ship six installable background components (Blueprint Grid, Perspective Grid,
Béton Brut, CRT Overlay, Data Rain, Exposed Wiring) built only from CSS and
inline SVG. Each one is a `registry.json` item with its own docs page, uses
colour tokens only, and has a static state under `prefers-reduced-motion`.

## Design reference

- Artboard: `project/Backgrounds.dc.html` on the
  [design mockups canvas](https://claude.ai/artifact/CbDg2ZHiJ3VsDc6iSdTdzx).
  Match layout, motion and details, not colours (overview § Features).
- Artboard → token mapping (hex is never used in components):
  - Blueprint Grid: navy `#1B2A3A` → `--ground-deep`. Lines are `--label`
    mixed to 35% (major, 120px) and 12% (minor, 24px).
  - Perspective Grid: `--ground-void` ground, `--signal` horizon (2px, glow)
    and grid lines (2px, 48px cells, 0.6 opacity), `perspective(240px)
    rotateX(64deg)`, top fade mask, 1.4s linear scroll by one cell.
  - Béton Brut: `--dim` base, fractal-noise layer (baseFrequency 0.55, 4
    octaves, 0.55 opacity) and a blot turbulence layer (0.012, 2 octaves, 0.25
    opacity), both desaturated. 2px `--surface` formwork seams and `--bg` tie
    holes on a 106×60 grid.
  - CRT Overlay: `--ground-deep` ground, scanlines (`--ground-void` at 45%,
    2px/4px), radial vignette (transparent 45% → `--ground-void` 75%),
    `steps(1)` opacity flicker over 4s (dips to 0.94 and 0.96).
  - Data Rain: `--ground-void` ground, 18 glyph columns in `--label` at mixed
    opacity, one column in `--signal`, `steps(28)` fall, 3–6.6s durations
    with negative delays, bottom fade to `--ground-void`.
  - Exposed Wiring: `--bg` ground, SVG traces from the artboard (viewBox
    `0 0 425 360`, `xMidYMid slice`) in `--dim`, a 2.4s `--signal` dash pulse
    on one trace, `--ground-deep` pads stroked `--label`, a `--surface` IC
    block stroked `--label` with `IC-07` in `--ink`.
- The artboard's chips, notes, "+" dimension marks, monolith square and
  "NO CARRIER" text are demo content for the docs previews. Only the
  Blueprint Grid crosshairs are part of a component (as an option).

## In scope

- Six components in `registry/ui/`: `blueprint-grid.tsx`,
  `perspective-grid.tsx`, `beton-brut.tsx`, `crt-overlay.tsx`, `data-rain.tsx`,
  `exposed-wiring.tsx`.
- New animation utilities in `styles/effects.css` for the four animated
  backgrounds, with a reduced-motion guard and flash-rate notes.
- Six `registry.json` items plus an `effects` description update. `public/r/`
  regenerated by `npm run registry:build`.
- Six docs pages at `app/docs/components/<item>/page.mdx`.

## Out of scope

- Using backgrounds in the docs site chrome or landing page (Feature 13).
- Final palette, new colour tokens or presets (Feature 12). No new colour
  tokens: the navy blueprint colour maps to `--ground-deep`.
- Canvas, WebGL, images, `motion` or GSAP.
- Playwright snapshots and CI (Feature 14).
- Any pause control (prop, built-in button or docs toggle). Decided at spec
  review: the backgrounds do not pause. Reduced motion is the only way to
  stop them.

## Build loop

`workflow.stepReview` is `feature`: build all steps, then stop for one review
of the whole feature. `workflow.checkpointCommits` is `disabled`: no commits
between steps. `/complete` makes the single feature commit. Run `npm run lint`
and `npx tsc --noEmit` after each step.

## Build steps

- [x] 1. **Shared component shape + static backgrounds (Blueprint Grid, Béton
  Brut).** Each background is a server-safe component (no `"use client"`)
  that renders a `div` with `relative isolate overflow-hidden`, the
  background layers in an `aria-hidden` absolutely positioned layer with
  `pointer-events-none` and `-z-10`, and `children` rendered directly after
  it. (Implementation note: `isolate` + `-z-10` replaces the planned
  `relative` children wrapper, so layout classes on the root apply to the
  children with no extra element.) Props:
  `ComponentProps<"div">` forwarded, `className` merged last with `cn()`.
  Blueprint Grid adds `minor` (number, 24), `major` (number, 120) and
  `crosshairs` (boolean, true: small `--ink` "+" marks at major
  intersections, CSS gradients only). Béton Brut adds `formwork` (boolean,
  true: seams and tie holes). Noise uses data-URI SVG backgrounds, like the
  existing `grain` utility, so no SVG `id`s can collide between instances.
  Done when: lint and typecheck pass and no hex colour appears in either file
  (`grep -E '#[0-9a-fA-F]{3,8}\b' registry/ui/blueprint-grid.tsx
  registry/ui/beton-brut.tsx` prints nothing). Rendering is confirmed in
  step 4 through the docs pages.
- [x] 2. **Animation utilities.** Add to `styles/effects.css`, each wrapped in
  `@media (prefers-reduced-motion: no-preference)` and listed in the
  layer-ownership comment: `perspective-scroll` (background-position by one
  cell, 1.4s linear; cell size from `--perspective-cell`), `crt-flicker`
  (4s `steps(1)` opacity, two dips per cycle: under 3 Hz),
  `data-rain` (falls from above the host to below it using `top` 0 → 100% plus
  `translateY(-100%)` → `none`, so it works at any host height; duration and
  delay from inline style; `steps(28)`), and `trace-pulse`
  (stroke-dashoffset 440 → 0, 2.4s linear). Each gets a one-line comment
  stating why it stays under 3 flashes per second (WCAG 2.3.1).
  Done when: the utilities exist, lint passes, and `npm run build` compiles
  CSS without errors.
- [x] 3. **Animated backgrounds (Perspective Grid, CRT Overlay, Data Rain,
  Exposed Wiring).** Same shape as step 1, with no pause prop or control
  (decided at spec review). Perspective Grid adds
  `cellSize` (number, 48). CRT Overlay renders scanlines and vignette
  *above* `children` (still `aria-hidden`, `pointer-events-none`), applies
  `crt-flicker` to the whole host, and adds `vignette` (boolean, true) and
  `flicker` (boolean, true). Data Rain adds `columns` (number, 18) and
  `signalColumn` (number, 7; out-of-range means no signal column); column
  glyphs, opacity, duration and delay come from a pure deterministic function
  of the index (the artboard formula), so server and client markup match.
  Exposed Wiring uses the artboard SVG; its `IC-07` text stays decorative.
  Done when: each component's animated layer is static under reduced motion
  (all motion comes from the guarded utilities), lint and typecheck pass,
  and no hex is used.
- [x] 4. **Registry items + docs pages.** Add six `registry:ui` items after
  `logo-wall`: names `blueprint-grid`, `perspective-grid`, `beton-brut`,
  `crt-overlay`, `data-rain`, `exposed-wiring`. `registryDependencies` are
  `["utils", "@cybr/tokens"]`, plus `"@cybr/effects"` for the four animated
  items; descriptions end with the "Requires …" sentence used by existing
  items. Update the `effects` item description to list the new utilities.
  Write six MDX pages following `warning-tape/page.mdx`: header, install,
  preview (artboard demo content such as chips, notes and "NO CARRIER" goes
  in the page, sized e.g. `h-90 w-full`), props table, Usage (stylesheet
  imports and example), States, Accessibility.
  Done when: `npm run build` succeeds (registry build + `next build`),
  `public/r/<item>.json` exists for all six, and each
  `/docs/components/<item>` renders in `npm run start`.

- [x] 5. **Repair after `/check` (verification failed).** Perspective Grid's
  floor painted over the children in Chrome when `perspective()` sat in the
  floor's own transform. Move the perspective to the background layer
  (`perspective-[240px] perspective-origin-[50%_46%]`) and keep only
  `rotateX(64deg)` on the floor. Also give the Exposed Wiring pulse path
  `pathLength={440}` so one dash cycle spans the trace and only one dash shows,
  matching its docs.
  Done when: a label panel inside Perspective Grid has no grid lines over it,
  the grid still scrolls and is static under reduced motion, Exposed Wiring
  shows one dash at rest, and lint, typecheck and `npm run build` pass.

## Data / contracts

- Registry item names (install ids, kebab-case) as listed in step 4; type
  `registry:ui`; file path `registry/ui/<name>.tsx`. Doc routes
  `/docs/components/<name>`.
- Public props as listed in steps 1 and 3; every background forwards
  `ComponentProps<"div">` and renders `children`.
- Colour tokens only (`--bg`, `--surface`, `--dim`, `--signal`, `--ink`,
  `--label`, `--ground-deep`, `--ground-void`); `--line` only for decoration.
  Glow (`box-shadow`/`text-shadow`) only on `--signal` elements.

## Notes for the AI

- Read `node_modules/next/dist/docs/` for anything Next-specific you are
  unsure of; the components are plain server-safe React.
- Accessibility: every decorative layer is `aria-hidden`; backgrounds never
  take pointer events; flicker and glitch-like motion stay under 3 Hz; nothing
  moves under reduced motion. Docs Accessibility sections must say that text
  over Béton Brut (`--dim`) needs `--ink` (about 4.7:1, re-check). For the
  four animated backgrounds, they must state plainly that the motion cannot be
  paused and stops only under reduced motion, which falls short of WCAG 2.2.2
  (Pause, Stop, Hide) when the background runs beside other content.
- Data Rain glyphs include `ア`; JetBrains Mono may fall back for it. That is
  acceptable, the column is decorative.
- Keep the "+" crosshair on Blueprint Grid sized from tokens
  (`--border-hair`) and coloured `--ink` like the artboard.
- Match comment density and style of `warning-tape.tsx` and `effects.css`.
