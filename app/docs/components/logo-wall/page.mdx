## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { LogoWall, LogoWallItem } from "@/components/ui/logo-wall";

export function Clients() {
  return (
    <LogoWall label="TRUSTED BY">
      <LogoWallItem href="https://example.com">
        <img src="/logos/example.svg" alt="Example Corp" className="h-6" />
      </LogoWallItem>
    </LogoWall>
  );
}
```

## States

- **Idle:** `--label` text in a cell with a transparent 2px border.
- **Hover:** linked logos turn `--signal`, text and border, in two hard steps over 90ms.
- **Focus-visible:** a 3px solid `--signal` outline inset inside the cell.
- **Reduced motion:** the hover change snaps with no transition.
- **Layout:** 2 columns below `sm` with the label across the top, 3 from `sm`, and one row from `lg` with a 220px label cell.

## Accessibility

- Each linked logo is a native `<a>`. Its accessible name comes from its content, so give logo images `alt` text naming the company.
- Unlinked cells are plain `<div>`s with no hover.
- The label is `--label` on `--bg` (7.43:1). Hovered text is `--signal` on `--bg` (4.64:1). If you override colours with `className`, keep text contrast at 4.5:1 or above.
