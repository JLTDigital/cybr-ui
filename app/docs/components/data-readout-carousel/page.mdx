## Usage

Needs both stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import { DataReadoutCarousel } from "@/components/ui/data-readout-carousel";

export function Readouts() {
  return (
    <DataReadoutCarousel
      label="SYSTEM READOUT"
      slides={[<p key="a">Uptime 99.98%</p>, <p key="b">Latency 42ms</p>]}
    />
  );
}
```

## Behaviour

- **Counter:** the current slide in `--signal` and the total in `--label`, both padded to 2 digits (`01 / 04`).
- **Stepping:** PREV and NEXT move one slide. Left and Right arrow keys do the same while focus is anywhere in the carousel, except in a text field inside a slide.
- **Ends:** without `loop`, PREV is disabled on the first slide and NEXT on the last, shown as `--dim` text with a not-allowed cursor. With `loop` they wrap.
- **Wipe:** after the first change, each new slide wipes in from the left in stepped 300ms frames. The first slide never animates on load.
- **Static:** before hydration and without JavaScript, slide 1 shows and the other slides are hidden. Under `prefers-reduced-motion` slides swap instantly.
- **Empty:** with no slides the counter reads `00 / 00` and both buttons are disabled. With one slide both buttons are disabled.
- No autoplay, so there is nothing to pause. Swipe is not built in; the buttons work on touch.

## Accessibility

- A `<section>` with `aria-roledescription="carousel"` and your `label` as its name. Each slide is a group with `aria-roledescription="slide"` and a label like "2 of 4".
- The slide area is `aria-live="polite"`, so screen readers announce the new slide after PREV or NEXT. Hidden slides are out of the accessibility tree.
- The buttons are named "Previous slide" and "Next slide"; the bracket and arrow glyphs are `aria-hidden`. At the ends the buttons are `aria-disabled` rather than `disabled`, so a focused button keeps focus and the arrow keys keep working; activating it does nothing.
- The counter and segment strip are `aria-hidden`, because the slide labels carry the position.
- `--label` on `--ground-deep` is 8.51:1, the `--signal` counter on `--ground-deep` is 5.31:1 and button text is `--ink` on `--ground-deep` at 16.74:1.
