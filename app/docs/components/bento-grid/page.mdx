## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { BentoGrid, BentoGridItem } from "@/components/ui/bento-grid";

export function Overview() {
  return (
    <BentoGrid>
      <BentoGridItem span={2}>Spec card</BentoGridItem>
      <BentoGridItem>Access card</BentoGridItem>
      <BentoGridItem>Hardware panel</BentoGridItem>
      <BentoGridItem span={4}>Stat band</BentoGridItem>
    </BentoGrid>
  );
}
```

## Anatomy

- **Grid:** a `--line` background showing through 2px (`--border-base`) gaps, so the gaps are the borders. A 2px `--line` border closes all four sides. The artboard is full-bleed and only shows top and bottom; a standalone component draws the full slab.
- **Columns:** 1 column, 2 from `sm`, 4 from `lg`. These are viewport breakpoints, not container queries, so in a narrow container 4 columns can get tight.
- **Cells:** `--bg` fill, 28px/32px padding, and a column stack with a 14px gap.
- **Spans:** a fixed class map, so every span class exists at build time.

## Accessibility

- The grid is plain `<div>` layout with no role. Give cells their own headings or landmarks when the content needs them.
- Source order is reading order on every breakpoint; spans never reorder content.
- The gap lines are background colour, not content.
- Text you put in cells sits on `--bg`: `--ink` is 14.6:1 and `--label` 7.43:1. If you override colours with `className`, keep text contrast at 4.5:1 or above.
