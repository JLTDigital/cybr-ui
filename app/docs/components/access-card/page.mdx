## Usage

Needs both stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import Image from "next/image";

import { AccessCard } from "@/components/ui/access-card";

export function Badge() {
  return (
    <AccessCard
      className="w-64"
      level="03"
      name="K. Morrow"
      idLine="ID 0x4F2A-91 · EXP 2099"
      photo={<Image src="/morrow.jpg" alt="K. Morrow" width={256} height={96} />}
    />
  );
}
```

## Anatomy

- **Card:** `--ink` fill, `--ground-deep` text and a 2px `--ink` border. The width comes from you.
- **Hazard band:** a 14px strip of the shared `hazard-stripes` utility. Its stripes are 12px, a little wider than the artboard's 8px, so a palette swap stays in one place.
- **Level row:** 10px bold label and a `--ground-deep` chip.
- **Photo slot:** 96px `--surface` box. Without a photo, a `--dim` crosshair marks it.
- **Name, ID line, barcode:** display name, small mono ID line, and a decorative 26px barcode.

## Accessibility

- The hazard band, crosshair and barcode are decorative and hidden from assistive tech.
- Give the photo real `alt` text, usually the person's name.
- Text is `--ground-deep` on `--ink`, and the level chip is `--ink` on `--ground-deep`. If you override colours with `className`, keep text contrast at 4.5:1 or above.
