## Usage

Needs the stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import { ExposedWiring } from "@/components/ui/exposed-wiring";

export function Hardware() {
  return (
    <ExposedWiring className="min-h-96 p-10">
      <h2 className="font-display text-display-md text-ink uppercase">Under the panel</h2>
    </ExposedWiring>
  );
}
```

## States

- **Running:** a 40px `--signal` dash runs along one trace every 2.4s.
- **Reduced motion:** the dash rests at the start of its trace.
- The artwork covers the root and is cropped, never stretched, at any aspect ratio.

## Accessibility

- The SVG is `aria-hidden` (its `IC-07` label included) and never takes pointer events.
- The pulse is a smooth slide with no flashing.
- **The motion cannot be paused.** It stops only under `prefers-reduced-motion`. Beside other content for more than 5 seconds, that falls short of WCAG 2.2.2 (Pause, Stop, Hide).
- Traces are `--dim` on `--bg`, low contrast by design, so `--ink` text on top stays readable.
