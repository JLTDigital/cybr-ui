## Usage

Needs both stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import { GlitchHeading } from "@/components/ui/glitch-heading";

export function Outage() {
  return <GlitchHeading as="h1">Signal lost</GlitchHeading>;
}
```

## Behaviour

- **Trigger:** always on. It is a CSS animation, so it needs no JavaScript and is server-safe.
- **Timing:** a 3.2s cycle. For about 300ms near the end of each cycle, a `--signal` copy and a `--neon-2` copy each jump through three clipped slices offset up to 7px sideways. The rest of the cycle shows the plain heading.
- **Type:** display font, uppercase, `text-display-md`, line-height 0.9, `--ink`. Override the size with `className`.
- **Static:** under `prefers-reduced-motion` the slice copies never render.

## Accessibility

- The slice copies are `aria-hidden` spans, not `::before`/`::after` content, so the heading text is read once.
- `as` sets the real heading level; the default is `h2`.
- Each burst is about 300ms once every 3.2s, so no second has more than three flashes (WCAG 2.3.1). It is never continuous.
- Use at most one glitch element per viewport. This page shows a single instance.
- Under `prefers-reduced-motion` it is a plain static heading.
- `--ink` on `--bg` is 14.63:1. If you override colours with `className`, keep text at 4.5:1 or above.
