## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css` after `@import "tailwindcss";`.

```tsx
import { HudBracketButton } from "@/components/ui/hud-bracket-button";

export function Action() {
  return <HudBracketButton onClick={() => console.log("lock")}>Target</HudBracketButton>;
}
```

## States

- **Idle:** `--ground-deep` fill, `--ink` label, 1px `--line` border, four 12px `--signal` corner brackets sitting 6px outside the box.
- **Hover:** label turns `--signal` and the brackets snap out a further 5px on `steps(3)` over 120ms.
- **Pressed:** the button presses in 3px (`--offset-hard-hover`) on both axes, without a transition.
- **Disabled:** `--surface` fill, `--label` text, 2px dashed `--dim` border; brackets turn `--dim` and do not move.
- **Focus-visible:** 3px solid `--signal` outline, offset 6px.

## Accessibility

- Renders a native `<button>`, so keyboard activation, focus and the button role come for free.
- `type` defaults to `button`, so it never submits a surrounding form unless you pass `type="submit"`.
- Keyboard focus shows a bold `--signal` outline offset from the button.
- `disabled` uses the native attribute: it leaves the tab order and is announced as unavailable. Hover and press effects are switched off while disabled.
- The four brackets are `aria-hidden` decoration; the accessible name is the label.
- Under `prefers-reduced-motion` the brackets still move on hover, but jump instead of stepping.
- Label text is `--ink` (and `--signal` on hover) on `--ground-deep`. If you override colours with `className`, keep text contrast at 4.5:1 or above.
