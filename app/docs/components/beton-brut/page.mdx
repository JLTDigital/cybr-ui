## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { BetonBrut } from "@/components/ui/beton-brut";

export function Bunker() {
  return (
    <BetonBrut className="min-h-96 p-10">
      <p className="max-w-prose bg-ground-deep p-4 font-mono text-ink">Poured in place. No cladding.</p>
    </BetonBrut>
  );
}
```

## States

- **Default:** grain and blotches on `--dim`, with formwork seams and tie holes.
- **Bare:** `formwork={false}` leaves only the concrete texture.
- **Reduced motion:** nothing animates, so there is no change.
- Both noise layers are data-URI SVGs, so several instances on one page never share SVG ids.

## Accessibility

- The texture is one `aria-hidden` layer behind the children and never takes pointer events.
- `--dim` is a mid grey and the noise varies it. Body text straight on the concrete needs `--ink` (about 4.7:1 on plain `--dim`; re-check if the palette changes). For small text, set it on a `--ground-deep` panel as in the example.
