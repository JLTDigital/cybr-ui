## Usage

Needs the stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import { DataRain } from "@/components/ui/data-rain";

export function Uplink() {
  return (
    <DataRain className="flex min-h-96 items-end p-10">
      <p className="bg-ground-deep px-3 py-2 font-mono text-sm text-ink">UPLINK ESTABLISHED</p>
    </DataRain>
  );
}
```

## States

- **Running:** columns fall in hard steps at different speeds and offsets, fading out at the bottom.
- **Reduced motion:** the columns rest at the top, still and readable as texture.
- Columns are generated from their index, not at random, so the server and browser render the same markup.
- Some glyphs (such as ア) are not in JetBrains Mono and fall back to a system font.

## Accessibility

- The whole rain layer is `aria-hidden`, so screen readers never hear the glyphs, and it never takes pointer events.
- The columns move in small steps; they do not flash.
- **The motion cannot be paused.** It stops only under `prefers-reduced-motion`. Beside other content for more than 5 seconds, that falls short of WCAG 2.2.2 (Pause, Stop, Hide).
- Set readable text on a solid `--ground-deep` panel, as in the example, so falling glyphs never sit behind it.
