## Usage

Installs `@base-ui/react`. Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
"use client";

import { useRouter } from "next/navigation";

import { CommandPalette } from "@/components/ui/command-palette";

export function Search() {
  const router = useRouter();
  return (
    <CommandPalette
      groups={[{ label: "DOCS", items: [{ value: "/docs/install", label: "Install" }] }]}
      onSelect={(href) => router.push(href)}
    />
  );
}
```

The trigger fits the `actions` slot of a Terminal Navbar. Mount one palette per page, because each one with `shortcut` on listens for ⌘K.

## States

- **Closed:** the `SEARCH` trigger with a `⌘K` key-cap. Hovering turns its border `--ink`.
- **Open:** a `--ground-void` backdrop at 80% covers the page, with no blur. The popup sits 15vh from the top on `--ground-deep` with a solid offset shadow. Focus is in the input after the `--signal` `>` prompt.
- **Filtering:** typing keeps items whose label contains the text, case-insensitive. The first match is always highlighted: `--ground-deep` text on a `--signal` row. The footer counts matches.
- **Empty:** no matches, or no groups, shows `NO MATCH // 0 RESULTS`.
- **Run:** Enter or a click calls `onSelect`, then closes. The next open starts with an empty query.
- Nothing animates, so there is no reduced-motion variant.

## Accessibility

- Built on Base UI's Dialog and Autocomplete. The dialog is modal and named by `label`. Focus moves to the input on open and returns to the trigger on close.
- The input is named "Search commands" and described by hidden instructions: arrows to move, Enter to run, Escape to close. The visible footer hint is `aria-hidden`.
- Up and Down move the highlight; Enter runs it. Escape, the hidden Close button or a backdrop click closes the palette.
- The shortcut ignores key presses while an input method is composing text.
- `--ink` on `--ground-deep` is 16.74:1, hints are `--label` on `--ground-deep` at 8.51:1 and the highlighted row is `--ground-deep` on `--signal` at 5.31:1.
