## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { SegmentedProgress } from "@/components/ui/segmented-progress";

export function Upload({ done }: { done: number }) {
  return <SegmentedProgress value={done} label="Uploading assets" phase="TRANSFER" />;
}
```

## States

- **Empty:** `000%` over an `--ink` framed track with no lit segments.
- **Partial:** `floor(value / max × segments)` segments lit in `--signal`; the readout rounds to the nearest whole percent and pads to 3 digits.
- **Full:** `100%` and every segment lit.
- **Out of range:** values below 0 show as 0, above `max` as full.
- Segments snap on and off. Nothing animates, so there is no reduced-motion variant.

## Accessibility

- The track is `role="progressbar"` with `aria-valuemin`, `aria-valuemax`, `aria-valuenow` and your `label` as its name.
- The big readout is `aria-hidden`, because the progressbar already exposes the value. The phase text stays readable.
- This is determinate only. For unknown durations, show a Boot Sequence Loader or your own status text instead.
- `--ink` on `--bg` is 14.6:1 and `--label` on `--bg` is 7.43:1. Lit `--signal` segments are not text, but keep them at 3:1 against the background (WCAG 1.4.11) if you override colours.
