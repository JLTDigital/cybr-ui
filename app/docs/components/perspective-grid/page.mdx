## Usage

Needs the stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import { PerspectiveGrid } from "@/components/ui/perspective-grid";

export function Horizon() {
  return (
    <PerspectiveGrid className="flex min-h-96 items-start justify-center pt-16">
      <h1 className="font-display text-display-lg text-ink uppercase">Sector 7</h1>
    </PerspectiveGrid>
  );
}
```

## States

- **Running:** the floor grid scrolls toward the viewer below a glowing `--signal` horizon at 46% height.
- **Reduced motion:** the grid is still; the horizon and grid stay visible.
- The monolith block in the preview is demo content from the artboard, not part of the component.

## Accessibility

- The horizon and floor are one `aria-hidden` layer behind the children and never take pointer events.
- The motion is a smooth slide with no flashing.
- **The motion cannot be paused.** It stops only under `prefers-reduced-motion`. Beside other content for more than 5 seconds, that falls short of WCAG 2.2.2 (Pause, Stop, Hide).
- Keep text above the horizon, on `--ground-void`. Text over the grid lines loses contrast.
