## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { StatusBar } from "@/components/ui/status-bar";

export function Header() {
  return <StatusBar items={["SYS:OK", "REV 0.1"]} signal={3} />;
}
```

## States

- **Default:** 28px strip on `--ground-void` with `--label` strings and a `--line` rule underneath.
- **Signal:** lit bars are `--signal`, unlit bars are `--line`, rising 4, 7, 10 and 13px.
- **Clock:** shows `--:--:-- UTC` on the server and during hydration, then the real UTC time, updated every second.
- **Narrow:** the left strings clip; the meter and clock keep their space.

## Accessibility

- A plain `<div>`, not a landmark. Place it above your `<nav>` or inside a `<header>`.
- The meter is `role="img"` with the label "Signal strength N of 4". The bars themselves carry no text.
- The clock is plain text, not a live region, so screen readers do not announce every second.
- `--label` on `--ground-void` is 9.19:1 and `--ink` on `--ground-void` is 18.09:1. If you override colours with `className`, keep text at 4.5:1 or above.
- Nothing animates; the clock text simply changes.
