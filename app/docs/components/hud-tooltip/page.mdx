## Usage

Installs `@base-ui/react`. Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { HudTooltip } from "@/components/ui/hud-tooltip";

export function Node() {
  return (
    <HudTooltip variant="lock" eyebrow="TARGET LOCKED" title="NODE 12" content="Relay online.">
      <button type="button">NODE 12</button>
    </HudTooltip>
  );
}
```

## States

- **Closed:** nothing is rendered.
- **Open:** appears instantly, with no fade. Hover opens it after 150ms, and keyboard focus opens it straight away.
- **Hovering the popup:** it stays open while the pointer moves from the trigger into it.
- **Flipped:** when there is no room on the chosen side, it moves to the opposite side. The lock leader line moves with it to the edge facing the trigger.
- **Pinned:** pass `open` or `defaultOpen`. The artboard's "pinned" tooltip is this state; there is no separate component.

## Accessibility

- Built on Base UI's Tooltip. It opens on hover and on keyboard focus, and Escape closes it.
- While open, the popup has `role="tooltip"` and the trigger points at it with `aria-describedby`. The trigger still needs its own accessible name, such as its text.
- Tooltips are supplementary. Base UI does not show them on touch devices, so never put information that people need only in a tooltip.
- Bracket corners, the leader line and its node are decorative and hidden from assistive tech.
- Text is `--ink` (readout) or `--ink` and `--label` (lock) on `--ground-void`, which is darker than `--bg`, so contrast is at least the 14.6:1 and 7.43:1 measured on `--bg`. If you override colours with `className`, keep text contrast at 4.5:1 or above.
