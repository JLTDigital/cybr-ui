## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import Image from "next/image";

import { HudImageFrame } from "@/components/ui/hud-image-frame";

export function Feed() {
  return (
    <HudImageFrame index="01" caption="CAM 04 · SECTOR NINE">
      <Image src="/sector-nine.jpg" alt="Loading bay at night" fill />
    </HudImageFrame>
  );
}
```

## Anatomy

- **Frame:** `--ground-void` fill, 1px `--line` border, 196px minimum height.
- **Brackets:** four 22px `--signal` corners, 3px thick, 10px in from the edges.
- **Reticle:** a 40px `--label` ring with short cross lines through the centre.
- **Scan line:** a static 2px `--signal` line at 38% height, 55% opacity. Nothing moves.
- **Index and caption:** an 88px outlined numeral at the bottom left and a mono caption at the bottom right.

## Accessibility

- Renders a `<figure>`; the caption is its `<figcaption>`.
- Give images real `alt` text. Use `alt=""` only when the caption already says everything.
- Brackets, reticle, scan line and the index numeral are decorative and hidden from assistive tech. The outlined numeral has no fill, so it makes no contrast claim; don't put meaning in it.
- The caption is `--label` on `--ground-void`. Over a bright image, check it stays readable.
