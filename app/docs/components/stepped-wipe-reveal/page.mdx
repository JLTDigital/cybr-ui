## Usage

Needs both stylesheets from `@cybr/tokens` and `@cybr/effects`, and `@cybr/use-reduced-motion` arrives with them. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import { SteppedWipeReveal } from "@/components/ui/stepped-wipe-reveal";

export function Slogan() {
  return (
    <h2 className="font-display text-5xl uppercase">
      <SteppedWipeReveal>Raw.</SteppedWipeReveal>
      <SteppedWipeReveal delay={300}>Loud.</SteppedWipeReveal>
    </h2>
  );
}
```

## Behaviour

- **Trigger:** wipes in once, the first time it scrolls into view.
- **Timing:** a left-to-right `clip-path` wipe in 12 hard steps over 1080ms, after `delay`.
- **Waiting:** clipped away until it is in view and its delay has passed.
- **Finished:** fully visible, and stays that way.
- **Static:** Before hydration, without JavaScript and under `prefers-reduced-motion`, it renders the content fully visible. On the client a line already in view can show for one frame before it clips and wipes.
- **Layout:** renders a block `span`, so each reveal is its own line. Typography comes from the parent or `className`.

## Accessibility

- The content is always in the DOM and only visually clipped, so screen readers read it straight away, without waiting for the wipe.
- The wipe runs once in 12 steps and never repeats, so it does not flash (WCAG 2.3.1).
- Under `prefers-reduced-motion` nothing is clipped and no wipe runs.
- It inherits colour. `--signal` text needs `--bg` or a large size on `--surface`, as in the preview's “Lit.”.
