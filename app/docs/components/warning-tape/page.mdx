## Usage

Needs the stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import { WarningTape } from "@/components/ui/warning-tape";

export function Construction() {
  return <WarningTape className="bg-ground-deep" items={["CAUTION // UNDER CONSTRUCTION", "RESTRICTED SECTOR"]} />;
}
```

## States

- **Running:** the chips scroll in reverse (left to right) along the tilted tape.
- **Hover or focus inside:** the scroll pauses.
- **Paused by the button:** stays paused until PLAY is pressed.
- **Reduced motion:** the tape is static and the button is not rendered.
- **No items:** a static, decorative stripe band, hidden from assistive tech, with no button. The demo stacks one under the signal tape, as on the artboard.
- The stripes reuse the shared `hazard-stripes` utility, so they are 12px rather than the artboard's 14px. A palette swap changes them in one place.

## Accessibility

- With items, the chips render once as a list and the second copy is `aria-hidden`. Without items, the whole tape is `aria-hidden`.
- The PAUSE/PLAY button meets WCAG 2.2.2 for keyboard and touch users. Its name is "PAUSE warning tape" / "PLAY warning tape". It sits unrotated in the top-right corner and has an `--ink` focus outline.
- The scroll is a smooth slide with no flashing.
- Chip text is `--ink` on `--ground-deep` chips, at least the 14.6:1 measured on `--bg`. If you override colours, keep text contrast at 4.5:1 or above.
