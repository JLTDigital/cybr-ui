## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { SpecCard, SpecCardAction } from "@/components/ui/spec-card";

export function Module() {
  return (
    <SpecCard
      meta="UNIT / D-01 · REV 2.6"
      title="Core module"
      action={<SpecCardAction href="/modules/core">VIEW SPEC →</SpecCardAction>}
      specs={[{ label: "STATUS", value: "ONLINE", accent: true }]}
    >
      Hardened compute node for the edge.
    </SpecCard>
  );
}
```

## Anatomy

- **Frame:** 2px `--ink` border, `--ground-deep` fill, and the artboard's 8px solid `--signal` offset shadow. The card keeps 8px of right and bottom margin so a tight parent doesn't clip the shadow.
- **Header:** mono meta text and a decorative 7-bar barcode over a 2px `--ink` rule.
- **Body:** title, description and action on the left; the spec list beside them from `sm`, stacked below on small screens.
- **Action:** `--ink` fill with a 4px `--signal` shadow that halves to 2px as the link moves 2px on hover.
- The 8px and 4px shadows are the artboard's own values. The `--offset-hard` token (6px, ink) belongs to the Hard-Offset Button.

## Accessibility

- Renders an `<article>` with a real heading; set its level with `titleAs`.
- The spec list is a `<dl>` with `<dt>`/`<dd>` pairs.
- The barcode is decorative and hidden from assistive tech.
- SpecCardAction is a native link with a bold 3px `--signal` focus outline. It renders `<a>`; for client-side routing, wrap the card in your router's link or style your own link with the same classes.
- Contrast on `--ground-deep`: `--ink` and `--label` text are above the overview figures for `--bg` (14.6:1, 7.43:1), and `--signal` values are above its 4.64:1. The action is `--ground-deep` on `--ink`. If you override colours with `className`, keep text contrast at 4.5:1 or above.
