## Usage

```tsx
import { HardOffsetButton } from "@/components/ui/hard-offset-button";

export function Cta() {
  return <HardOffsetButton onClick={() => console.log("deploy")}>Deploy now</HardOffsetButton>;
}
```

## States

- **Idle:** `--signal` fill, `--ground-deep` label, 3px solid `--ink` border and a 6px solid `--ink` offset shadow.
- **Hover:** steps 3px toward the shadow, which shrinks to 3px (`steps(2)`, 90ms).
- **Pressed:** steps the full 6px so it sits flush, with no shadow.
- **Disabled:** `--surface` fill, `--label` text, 2px dashed `--dim` border, no shadow and no movement.
- **Focus-visible:** 3px solid `--signal` outline, offset 6px.

## Accessibility

- Renders a native `<button>`, so keyboard activation, focus and the button role come for free.
- `type` defaults to `button`, so it never submits a surrounding form unless you pass `type="submit"`.
- Keyboard focus shows a bold `--signal` outline offset from the shadow.
- `disabled` uses the native attribute: it leaves the tab order and is announced as unavailable.
- Under `prefers-reduced-motion` the hover and press offset still apply, but without a transition.
- Label text is `--ground-deep` on `--signal`. If you override colours with `className`, keep text contrast at 4.5:1 or above.
