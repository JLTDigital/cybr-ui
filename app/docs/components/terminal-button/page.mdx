## Usage

Needs both stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import { TerminalButton } from "@/components/ui/terminal-button";

export function Action() {
  return <TerminalButton onClick={() => console.log("run")}>execute</TerminalButton>;
}
```

## States

- **Idle:** `--ground-void` fill, `--signal` label after a `> ` prompt, 1px `--line` border, and a block cursor blinking once a second.
- **Hover:** inverts to a `--signal` fill with `--ground-void` text and a `--signal` border.
- **Pressed:** the button presses in 3px (`--offset-hard-hover`) on both axes, without a transition.
- **Disabled:** `--surface` fill, `--label` text, 2px dashed `--dim` border; the cursor stays solid.
- **Focus-visible:** 3px solid `--signal` outline, offset 6px.

## Accessibility

- Renders a native `<button>`, so keyboard activation, focus and the button role come for free.
- `type` defaults to `button`, so it never submits a surrounding form unless you pass `type="submit"`.
- Keyboard focus shows a bold `--signal` outline offset from the button.
- `disabled` uses the native attribute: it leaves the tab order and is announced as unavailable. Hover and press effects are switched off while disabled.
- The `> ` prompt and the cursor are `aria-hidden`, so the accessible name is the label alone.
- The cursor blinks at 1Hz over a small area, under the 3-flashes-per-second limit (WCAG 2.3.1). Under `prefers-reduced-motion` it is a solid block.
- `--signal` on `--ground-void` is 5.74:1 in both directions (idle and hover). If you override colours with `className`, keep text contrast at 4.5:1 or above.
