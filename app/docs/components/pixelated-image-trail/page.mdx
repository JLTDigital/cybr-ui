## Usage

Needs the stylesheet from `@cybr/tokens`; `@cybr/use-reduced-motion` arrives with it. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { PixelatedImageTrail } from "@/components/ui/pixelated-image-trail";

export function Hero() {
  return (
    <PixelatedImageTrail className="h-96" images={["/work/01.jpg", "/work/02.jpg"]}>
      <h1>Selected work</h1>
    </PixelatedImageTrail>
  );
}
```

## Behaviour

- **Drop:** moving a mouse or pen `spacing` px drops the next image as a tile centred on the pointer, with a 1px `--line` border.
- **Resolve:** each tile steps through 24, 12, 6, 3 and 1px blocks at 70ms a step, holds sharp for 400ms, then steps back through 3, 12 and 24px and disappears. About 1 second per tile, with no smooth fades.
- **Limit:** at most `max` tiles at once; a new drop removes the oldest.
- **Off:** no trail for touch, under `prefers-reduced-motion`, before hydration or without JavaScript. The children render as normal.
- **No images:** if none of the images load, there is no trail.
- The demo plates in `/demo` are docs assets only. They are not installed with the component.

## Accessibility

- The trail layer is `aria-hidden` and ignores pointer events, so screen readers and clicks only meet your children.
- Tiles appear only when the user moves the pointer, and stop when it stops. They are small tiles, not full-screen flashes, and the resolve steps do not repeat as a flicker.
- Under `prefers-reduced-motion` nothing appears at all. If you put meaningful images in the trail, also show them somewhere static: the trail is decoration.
