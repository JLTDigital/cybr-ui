## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { HardwarePanel, HardwarePanelStatus } from "@/components/ui/hardware-panel";

export function Power({ uplink }: { uplink: boolean }) {
  return (
    <HardwarePanel title="PWR / BUS 04">
      <HardwarePanelStatus label="MAIN" on />
      <HardwarePanelStatus label="UPLINK" on={uplink} />
    </HardwarePanel>
  );
}
```

## Anatomy

- **Panel:** `--surface` fill with a 2px `--dim` border and extra left padding for the cable channel.
- **Rivets:** four 9px round `--dim` rivets with an inset `--label` highlight. Rivets are a round decorative motif; nothing interactive is rounded.
- **Cable channel:** a 12px strip of `--bg` and `--line` bands down the left edge.
- **Status row:** label on the left; state text and a 10px LED on the right. On is a `--signal` square with a small glow; off is a 2px `--label` outline.

## Accessibility

- Renders a `<section>` with a real heading, so it shows up as a named region in the outline. Set the level with `titleAs`.
- Every state is spelled out in text. The LED only repeats it, so state never depends on colour.
- Rivets, the cable channel and LEDs are decorative and hidden from assistive tech.
- Text is `--ink` on `--surface`. If you override colours with `className`, keep text contrast at 4.5:1 or above.
- Nothing animates.
