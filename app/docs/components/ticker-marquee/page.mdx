## Usage

Needs the stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

```tsx
import { TickerMarquee } from "@/components/ui/ticker-marquee";

export function News() {
  return <TickerMarquee aria-label="Latest updates" items={["// REV 0.1 LIVE", "// SYS:OK", "// NEW DROP"]} />;
}
```

## States

- **Running:** the items scroll right to left at a steady, linear speed.
- **Hover or focus inside:** the scroll pauses and resumes when the pointer or focus leaves.
- **Paused by the button:** stays paused until PLAY is pressed, even after the pointer leaves.
- **Reduced motion:** the band is static, showing the first items, and the button is not rendered.
- **Empty:** with no items, the band renders with no track and no button.

## Accessibility

- The items render once as a list. The second copy that makes the loop seamless is `aria-hidden`, so screen readers hear each item once.
- Moving content that runs longer than 5 seconds needs a way to pause it (WCAG 2.2.2). The visible PAUSE/PLAY button gives keyboard and touch users that control, and hover and focus pause it too.
- The button's visible text is in its accessible name ("PAUSE ticker" / "PLAY ticker"). Its focus outline is `--ink`, because a `--signal` outline would not show on the `--signal` band.
- The scroll is a smooth slide with no flashing.
- `--ground-deep` text on `--signal`, the overview's text-on-accent pair. If you override colours with `className`, keep text contrast at 4.5:1 or above.
