## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { MonolithFooter } from "@/components/ui/monolith-footer";

export function SiteFooter() {
  return (
    <MonolithFooter
      columns={[
        { heading: "LIBRARY", items: [{ label: "Docs", href: "/docs" }] },
        { heading: "SYSTEM", items: [{ text: "REV 0.1" }] },
      ]}
    />
  );
}
```

## States

- **Default:** columns on `--ground-deep` with `--signal` headings and `--label` items, over an `--ink` wordmark cropped by the bottom and right edges.
- **Link hover:** the link turns `--ink`.
- **Focus-visible:** a 3px solid `--signal` outline 2px outside the link.
- **Narrow:** columns drop from 4 to 2 below the `sm` breakpoint, and the wordmark shrinks with the viewport (`clamp(4.5rem, 17vw, 13.375rem)`). It always crops, and never widens the page.
- Nothing animates.

## Accessibility

- A `<footer>` element, which is the page's contentinfo landmark when it is not inside another sectioning element.
- Each column is a list named by its heading.
- The wordmark is `aria-hidden` and ignores pointer events. Put your real site name in a link or text elsewhere if it matters to screen reader users.
- `--label` on `--ground-deep` is 8.51:1 and `--signal` headings on `--ground-deep` are 5.31:1.
