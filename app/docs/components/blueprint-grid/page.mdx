## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { BlueprintGrid } from "@/components/ui/blueprint-grid";

export function Hero() {
  return (
    <BlueprintGrid className="flex min-h-96 items-center justify-center">
      <h1 className="font-display text-display-lg text-ink uppercase">Drafted</h1>
    </BlueprintGrid>
  );
}
```

## States

- **Default:** minor and major grids on `--ground-deep`, with crosshairs on the major intersections.
- **No crosshairs:** `crosshairs={false}` leaves just the two grids.
- **Reduced motion:** nothing animates, so there is no change.
- The artboard's navy ground maps to `--ground-deep`; colours follow the tokens, not the mockup.

## Accessibility

- The grid is one `aria-hidden` layer behind the children and never takes pointer events.
- Grid lines are faint `--label` mixes, so text on top keeps the contrast of `--ground-deep`. Use `--ink` or `--label` for text.
