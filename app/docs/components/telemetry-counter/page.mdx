## Usage

Needs the stylesheet from `@cybr/tokens`, and `@cybr/use-reduced-motion` arrives with it. After the install, import the tokens in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { TelemetryCounter } from "@/components/ui/telemetry-counter";

export function Throughput() {
  return <TelemetryCounter className="text-3xl" value={1284} />;
}
```

## Behaviour

- **Trigger:** starts the first time it scrolls into view, then never again.
- **Timing:** counts from 0 to `value` over `duration` (2250ms by default), easing out, and lands exactly on `value`.
- **Waiting:** shows 0, formatted, until it is in view.
- **Finished:** shows `value`. A later change to `value` shows the new value at once.
- **Static:** Before hydration, without JavaScript and under `prefers-reduced-motion`, it renders the final value. On the client it can show the final value for one frame before resetting to 0.
- **Not a number:** a non-finite `value` (`NaN`, `Infinity`) is formatted as-is and never animates.
- **Type:** display font with tabular figures, so digits do not shift while counting. Set the size with `className`.

## Accessibility

- The final value sits in a visually hidden copy; the counting digits are `aria-hidden`. Screen readers read the real number once.
- The count runs once and changes digits, not colours, so it does not flash (WCAG 2.3.1).
- Under `prefers-reduced-motion` it shows the final value with no count.
- It is a plain number. Give it a visible label, as in the `dl` above, so the figure has meaning.
- It inherits colour, so keep the text at 4.5:1 or above against its background.
