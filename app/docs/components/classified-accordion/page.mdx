## Usage

Installs `@base-ui/react`. Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { ClassifiedAccordion, ClassifiedAccordionItem } from "@/components/ui/classified-accordion";

export function Faq() {
  return (
    <ClassifiedAccordion>
      <ClassifiedAccordionItem value="install" id="F-01" question="HOW DO I INSTALL ONE?">
        Run npx shadcn add @cybr/&lt;name&gt;.
      </ClassifiedAccordionItem>
    </ClassifiedAccordion>
  );
}
```

## States

- **Closed:** the question row with a `+` mark.
- **Hover:** the row fills with `--surface` and the id switches from `--signal` to `--ink`, because small `--signal` text does not pass contrast on `--surface`.
- **Focus-visible:** a 3px solid `--signal` outline inset inside the row.
- **Open:** the mark becomes `−` and the answer shows on `--ground-deep` under a dashed rule. Opening is instant, with no height animation.
- **One at a time:** opening an item closes the others, and clicking an open item closes it. Pass `multiple` to change this. The artboard opens F-01; the component starts with all items closed, so this demo passes `defaultValue`.

## Accessibility

- Built on Base UI's Accordion. Each trigger is a native `<button>` with `aria-expanded` and `aria-controls`, inside a heading (`h3` by default; set `headingAs`).
- Enter and Space toggle an item. Tab moves between triggers.
- The `+` and `−` marks are decorative; the open state comes from `aria-expanded`.
- Question text is `--ink` on `--bg` (14.6:1). Answers are `--label` on `--ground-deep`, darker than `--bg`, so at least 7.43:1. If you override colours with `className`, keep text contrast at 4.5:1 or above.
- Nothing animates.
