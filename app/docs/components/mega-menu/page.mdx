## Usage

Installs `@base-ui/react`. Needs both stylesheets from `@cybr/tokens` and `@cybr/effects`. After the install, import them in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
@import "../styles/cybr-effects.css";
```

Put it inside a `TerminalNavbar` as `children`, or inside your own `<nav>`:

```tsx
import { MegaMenu } from "@/components/ui/mega-menu";
import { TerminalNavbar } from "@/components/ui/terminal-navbar";

export function SiteNav() {
  return (
    <TerminalNavbar links={[{ label: "DOCS", href: "/docs" }]}>
      <MegaMenu
        label="COMPONENTS"
        columns={[{ heading: "BUTTONS", links: [{ label: "Glitch", href: "/docs/glitch" }] }]}
        feature={{ eyebrow: "NEW DROP", title: "GLITCH BUTTON →", href: "/docs/glitch" }}
      />
    </TerminalNavbar>
  );
}
```

## States

- **Closed:** the trigger reads `LABEL +` in `--label`, with the `+` in `--signal`.
- **Hover:** the trigger fills with `--bg` and turns `--ink`. Hovering also opens the panel after Base UI's short delay.
- **Open:** the trigger stays filled and the mark becomes `−`. The panel drops below the trigger: columns on `--bg` separated by 2px `--line` gaps, then the promo tile.
- **Link hover:** column links turn from `--label` to `--signal`.
- **Focus-visible:** a 3px solid `--signal` outline inset inside the trigger, each link and the promo tile.
- **Narrow:** the panel stays inside the viewport and drops to 2 columns, then 1, with the promo tile last.
- Opening and closing are instant, with no transition, so there is no reduced-motion variant.

## Accessibility

- Built on Base UI's NavigationMenu. The trigger is a `<button>` with `aria-expanded`. Enter or Space toggles the panel and ArrowDown opens it. Tab moves on from the trigger into the panel's links.
- Escape closes the panel and returns focus to the trigger. Clicking outside or tabbing out of the menu also closes it.
- Each column's links are a list named by its heading. The `+`/`−` mark is `aria-hidden`.
- The root is a `<div>`, so the menu does not add a second navigation landmark inside a `TerminalNavbar`.
- `--label` on `--bg` is 7.43:1, `--signal` on `--bg` (link hover) is 4.64:1 and `--ink` on `--ground-deep` (promo title) is 16.74:1.
