## Usage

Needs the stylesheet from `@cybr/tokens`. After the install, import it in `app/globals.css`:

```css
@import "tailwindcss";
@import "../styles/cybr-tokens.css";
```

```tsx
import { TerminalNavbar, TerminalNavbarCta } from "@/components/ui/terminal-navbar";

export function SiteNav() {
  return (
    <TerminalNavbar
      links={[
        { label: "INDEX", href: "/" },
        { label: "DOCS", href: "/docs", current: true },
      ]}
      actions={<TerminalNavbarCta href="/install">INSTALL →</TerminalNavbarCta>}
    />
  );
}
```

Links are plain `<a>` elements. To use client-side routing, edit the installed source and swap them for your framework's link component.

## States

- **Idle link:** `--label` mono text between 2px `--line` rules.
- **Hover:** the link fills with `--bg` and the text turns `--ink`.
- **Current:** `[ LABEL ]` in `--signal`.
- **Focus-visible:** a 3px solid `--signal` outline inset inside the link, wordmark or CTA. The CTA turns `--ink` on hover and focus so the outline shows against it.
- **Narrow (under 48rem of navbar width):** the bar shows only the wordmark and a `MENU` button with a 3-bar icon. Under 20rem the word MENU is visually hidden and only the icon shows; it is still the button's name. The breakpoint is a container query on the navbar's own width, not the viewport, so it behaves the same in a sidebar layout or a full-width header.
- **Menu open:** the button fills with `--bg` and its icon becomes an ×. A panel drops over the page below the bar on `--ground-deep`, with the links as full-width 48px rows, then any `children`, then the actions. Opening and closing are instant.
- **Menu closes** when you press the button again, press Escape, follow a link in the panel, or press anywhere outside the navbar.
- **Wide but crowded:** if the links still do not fit, the link row scrolls sideways with its scrollbar hidden; focusing a link scrolls it into view.

## Accessibility

- A `<nav>` landmark named "Primary" by default, with the links in a list.
- The current link has `aria-current="page"`. Its brackets are `aria-hidden`, so it reads as "COMPONENTS, current page".
- Tab order runs wordmark, links, any children, then the actions. When narrow it runs wordmark, `MENU`, then the panel's links, children and actions.
- `MENU` is a disclosure button: `aria-expanded` reports the state and `aria-controls` points at the panel. Its name stays "MENU" in both states, and the icon is `aria-hidden`.
- The closed panel is `display: none`, so its links leave the tab order and the accessibility tree. Escape closes it and puts focus back on `MENU`. There is no focus trap, because the panel is part of the page, not a modal.
- The demo's ⌘K hint is decorative and `aria-hidden`. If you wire up a real search, make it a button with a name.
- `--label` on `--ground-deep` is 8.51:1, `--signal` on `--ground-deep` is 5.31:1 and hover text is `--ink` on `--bg` at 14.63:1. CTA text is `--ground-deep` on `--signal` at 5.31:1.
- Nothing animates, including the icon change, so there is no reduced-motion variant.
